DOTA SHOP — BEGINNER PROJECT
============================

WHAT'S INCLUDED
- index.html: page structure and content
- style.css: colors, layout, responsive styling
- script.js: sample listings, search, categories, sorting, and cart

HOW TO RUN IN VISUAL STUDIO CODE
1. Download and extract dota-shop.zip.
2. Install Visual Studio Code: https://code.visualstudio.com/
3. In VS Code, choose File > Open Folder, then select the extracted "dota-shop" folder.
4. Open index.html.
5. Easiest option: install the "Live Server" extension by Ritwick Dey. Click "Go Live" in the VS Code status bar. Your browser will open the site.
6. If you don't want an extension, double-click index.html in File Explorer to open it in your browser. Live Server is better while editing.

HOW TO CUSTOMIZE
- Edit the products array near the top of script.js to change item names, categories, prices, rarity labels, and symbols.
- Edit CSS variables at the top of style.css to change the main colors.
- Edit index.html to change navigation, headings, footer, or page sections.

IMPORTANT
This is a front-end demo. Cart contents are temporary and reset when the page reloads. There is no real login, database, Steam inventory connection, payment processing, or item delivery. Before taking payments or selling digital items, add a secure backend, order handling, authentication, and a legitimate fulfillment process. Do not collect Steam passwords. Use official authentication flows if you later add Steam sign-in.

CUSTOM LOGO
-----------
Your custom logo is installed at images/dota-logo.png.
To replace it later, overwrite that image with your own logo and keep the same filename.
